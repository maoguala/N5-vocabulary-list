出かける　でかける　go out / go somewhere

出る　でる　leave / go out / graduate

着く　つく　arrive / reach
※「つく」は、到着する意味では通常「着く」と書きます。

会う　あう　meet / see

待つ　まつ　wait

デート　date / romantic date

約束　やくそく　promise / appointment / arrangement / plan / date
※「arrangement」の拼字修正。「約束」は文脈により「約定、約會、安排」。

用事　ようじ　errand / something to do / business
※通常不是 mission 或 event。

都合がいい　つごうがいい　be convenient / be available / have time

都合が悪い　つごうがわるい　be inconvenient / not be available / not have time

だめです　だめです　That's no good / You can't / It's not possible
※「denied」通常不是這個日常句型最自然的翻譯。

変える　かえる　change / alter / switch

お出かけですか　おでかけですか　Are you going out? / Are you going somewhere?

ちょっと〜まで　ちょっと〜まで　I'm just going to [place] for a bit. / I'm just going as far as [place].
※例如：ちょっとコンビニまで。= I'm just going to the convenience store.

よかったら〜　よかったら〜　if you'd like... / if you're interested... / if it's convenient for you...
※依照後面接的內容選擇翻譯。

すみません　すみません　Excuse me / I'm sorry / Thank you
※依照情境可表示打擾、道歉或帶有歉意的感謝。

〜でも　〜でも　something like ... / ... or something
※例如：コーヒーでも飲みませんか。= Would you like to have coffee or something?

〜ませんか　〜ませんか　Would you like to ...? / Won't you ...?
※用來禮貌地邀請對方。

〜はちょっと　〜はちょっと　... is a little difficult / I'm afraid ... won't work
※常用來委婉拒絕；不只是「a little bit」。

残業ですが　ざんぎょうですが　I have to work overtime, but... / I'm working overtime, so...
※如果要表達「很抱歉，但……」，可依情境說：I'm sorry, but...

また今度お願いします　またこんどおねがいします　Maybe next time. / Please ask me again another time.
※常用來婉拒邀約並表示下次有機會再說；自然英文需依情境調整。

チャンス　chance / opportunity

行ってきます　いってきます　I'm off. / I'll be back.
※出門時對留在家裡的人說的固定用語。

いってらっしゃい　いってらっしゃい　See you later. / Take care. / Have a good day.
※對要出門的人說的固定用語。

ただいま　ただいま　I'm home. / I'm back.

おかえりなさい　おかえりなさい　Welcome home. / Welcome back.
